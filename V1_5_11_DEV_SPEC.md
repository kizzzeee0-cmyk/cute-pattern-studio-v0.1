# Cute Pattern Studio v1.5.11

- Added four distinct watercolor aqua styles inspired by the supplied references:
  - 아쿠아 밀키: cyan watercolor wash + milky white center/right
  - 아쿠아 스파클: turquoise watercolor wash + sparse soft white sparkles
  - 아쿠아 프로스트: aqua + lavender frost wash with a clear milky center
  - 워터 클라우드: overlapping translucent cloud-like watercolor blooms
- Existing watercolor blotch styles remain available.
- Added `빛가루 / 반짝임` control for sparkle density.
- All styles remain square full-canvas backgrounds; no circular frame is generated.
