# Cute Pattern Studio v2.0.7

패턴 편집 중심으로 복원한 안정화 업데이트입니다.

## v2.0.5
- 완성형 디자인 배경 영역 제거
- **점선 체크 / Dashed Grid** 패턴 추가
  - 선 색상 / 투명도 / 두께
  - 점선 길이 / 점선 간격
  - 격자 가로 / 세로 간격
  - 전체 회전
  - X / Y 오프셋
  - round line cap
- 대표색을 **Anchor Color(가장 진한 기준색)** 로 사용하는 자동 톤 변환
- 기존 7색 빠른 선택 유지
- 자유 컬러 피커 / HEX / 스포이드 지원
- 거의 흰색이던 영역은 선택색의 아주 옅은 틴트만 적용
- 좌측 패턴 라이브러리 휠 스크롤 안정화
- 기존 레이어, 배경, 수채화, 비네트, 업로드 에셋, 프리셋 저장, PNG/심리스 저장 기능 유지

기본 작업 크기: 2000 × 2000px

## v2.0.5 추가 수정
- 상단 패턴 카테고리 탭이 항상 보이도록 레이아웃 복구
- 점선 체크의 `패턴 크기`를 전체 격자 스케일로 연결
- 가로/세로 격자 간격은 기존대로 개별 조정 가능


## v2.0.5 추가 수정
- 패턴 카테고리 탭을 라이브러리 상단으로 이동하고 항상 표시되도록 복구
- 점선 체크의 전체 크기가 격자 간격뿐 아니라 점선 길이/간격/두께에도 함께 적용
- 점선 체크는 Anchor Color 자동 변경 시 캔버스 배경색을 강제로 바꾸지 않음
- 흰색 점선 기본 투명도를 38%로 조정해 파스텔 배경에서 더 안정적으로 보이도록 수정


## v2.0.5
- 레이어드 패브릭 플래드의 45° 해칭 범위를 확대
- 중간 진함 이상 밴드/체크 영역에 빠짐없이 해칭 적용
- 해칭 사용 ON/OFF 토글
- 해칭 불투명도 0~100% 조절
- 기본 해칭 불투명도 40%


## v2.0.5
- 땡땡이/도트 계열은 모든 반복 도형을 한 가지 색상으로 통일
- 도트, 하트, 별, 반짝이, 리본, 꽃, 구름, 물방울 등 단순 반복 모양의 크기를 완전히 동일하게 고정
- 불규칙 도트도 위치만 흔들릴 수 있고 도트 자체 크기는 동일
- 단순 모양 패턴의 개별 색상 모드에는 '모양 색상' 1개만 표시
- 단순 모양 패턴에서는 '요소 크기 랜덤'을 비활성화해 실제 렌더 결과와 UI를 일치


## v2.0.6
- 도트·하트·별·리본·꽃·구름·물방울 등 단순 반복 모양의 개별 방향을 완전히 동일하게 고정
- 단순 모양은 색상 1색 · 크기 동일 · 방향 동일 규칙으로 렌더링
- 기존 저장값에 각도 랜덤이 켜져 있어도 자동으로 고정 방향으로 복구
- 단순 모양 패턴에서는 '요소 각도 랜덤' 옵션을 비활성화
- 전체 방향은 기존 '회전' 슬라이더로 모든 반복 요소를 함께 회전


## v2.0.7
- 하트·도트·별·리본·꽃·구름·물방울 등 단순 모양 패턴을 **2줄 1세트(A/B)** 방식으로 반복
- B줄은 기본적으로 A줄 요소 사이의 중간 지점에서 시작하도록 자동 반 칸 이동
- A줄: X 위치 / Y 위치 / 각도 개별 조절
- B줄: X 추가 이동 / Y 위치 / 각도 개별 조절
- 3번째 줄부터 A/B 설정을 그대로 반복
- 요소 색상과 크기는 기존처럼 완전히 동일하게 유지
- 요소 단위 랜덤 위치·크기·각도 대신 줄 단위 배치 설정 사용
- 전체 패턴 회전 및 전체 X/Y 이동은 기존 공통 컨트롤 유지
