# Cute Pattern Studio v1.5

Cute Pattern Studio는 귀여운 패턴 배경을 만들고 PNG / 심리스 타일 PNG로 저장하는 정적 웹앱이야.
Cloudflare Pages + Functions 구조를 사용하고, v1.5에서는 **원형 프사용 햇살/광택 배경 패턴**이 추가되었어.

## v1.5 핵심 변경점
- **썬버스트 원형 패턴 추가**
  - 햇살이 방사형으로 퍼지는 원형 프사 배경
  - 오렌지 외곽선 + 중앙 글로우 + 반짝이 포인트 포함
- **글로시 썬 원형 패턴 추가**
  - 부드러운 그라데이션 면 + 광택 스트릭 + 반짝이/도트 포인트 포함
- **신규 카테고리 `원형 프사` 추가**
  - 원형 중심 디자인을 빠르게 찾을 수 있음

## 사용 팁
- 추천 색 조합:
  - 색상1: 연한 크림 / 아이보리
  - 색상2: 노랑
  - 색상3: 주황
  - 색상4: 흰색(반짝이)
  - 선색: 진한 오렌지
- `크기`로 원의 비율을, `회전`으로 햇살 방향을, `디테일`로 방사선 밀도를 조정하면 좋아.
