# Cute Pattern Studio v0.4

Cute Pattern Studio는 **2000×2000 PNG 패턴 배경 생성용 정적 웹앱**입니다.  
GitHub에 업로드하고 Cloudflare Pages로 바로 배포할 수 있습니다.

## 이번 v0.4에서 반영한 내용

### 1) 레이어 구조 변경
- **기본 레이어 1개만 켜진 상태로 시작**
- 필요할 때만 **레이어 추가** 가능
- 기본 레이어는 항상 켜짐
- 추가 레이어는 켜기/끄기/삭제 가능
- 현재 레이어를 복제해서 새 레이어로 추가 가능

### 2) 배경색 + 패턴 저장 문제 수정
이전 버전에서:
- 미리보기에서는 배경이 섞여 보이는데
- 저장하면 배경 없이 패턴만 투명 PNG처럼 저장되는 문제가 있었음

v0.4에서는 이를 수정해서:
- **미리보기와 저장 결과가 동일하게 보이도록 개선**
- `투명 배경`이 꺼져 있으면 **선택한 배경색 + 패턴이 합쳐진 한 장의 PNG**로 저장
- `투명 배경`이 켜져 있으면 **투명 배경 패턴 PNG**로 저장

### 3) 패턴 종류 추가
체크/플래드 외에 귀여운 패턴 선택지를 조금 더 늘렸습니다.

추가 예시:
- 키라 스파클
- 잔리본
- 퍼프 하트
- 캔디 스타
- 데이지 도트

### 4) 유지되는 주요 기능
- 업로드 SVG/PNG/JPG 반복 패턴화
- SVG 단색 변환
- 레이어별 색상 / 크기 / 간격 / 회전 / 불규칙함 / 투명도 / 디테일 조절
- 즐겨찾기
- 내 프리셋 저장
- 참고 이미지 팔레트 자동 추출
- 심리스 타일 PNG 저장

## 사용 흐름

### 기본 패턴 배경 만들기
1. 패턴 선택
2. 배경 섹션에서 배경색 선택
3. 레이어 색상 / 크기 / 간격 조절
4. 필요하면 `레이어 추가`
5. `PNG 저장`

### 업로드한 투명 PNG를 패턴으로 만들기
1. 왼쪽 업로드 박스에 PNG/SVG/JPG 업로드
2. 현재 레이어에 자동 연결
3. `업로드 에셋` 모드에서 반복 방식 선택
4. 크기 / 간격 / 회전 / 불규칙함 조절
5. 배경색까지 맞춘 뒤 저장

## 파일 구성
- `index.html` — 메인 UI
- `styles.css` — 스타일
- `patterns.js` — 패턴 렌더러
- `app.js` — 앱 로직
- `V0_4_PLAN.md` — 이번 업데이트 정리 + 다음 단계 계획서

## GitHub + Cloudflare Pages 배포
1. 이 폴더 전체를 GitHub 저장소에 업로드
2. Cloudflare → Workers & Pages → Create Application
3. Pages → Import an existing Git repository
4. Framework preset: `None`
5. Build command: 비워두거나 `exit 0`
6. Build output directory: `.`
7. Deploy

## 참고
- 업로드한 에셋/즐겨찾기/내 프리셋은 브라우저 `localStorage`에 저장됩니다.
- 업로드 데이터가 아주 많아지면 브라우저 저장 공간 제한에 걸릴 수 있습니다.
