# Cute Pattern Studio v1.5.1

v1.5.1은 v1.5에서 발생한 패턴 라이브러리/미리보기 문제를 되돌리고, 사용자가 원한 **네모 캔버스 전체에 적용되는 햇살·광택 디자인**을 새로 추가한 수정 버전이야.

## 이번 수정의 핵심
- v1.4 안정 구조를 기준으로 다시 구성
- 좌측 패턴 라이브러리 전체 목록이 안 보이던 문제 복구
- 기존 체크/도트/리본/하트/별/오브젝트 패턴 미리보기 복구
- 원형 틀/원형 프레임 프리셋은 추가하지 않음
- 첨부 이미지의 **원 안쪽 디자인 요소만 참고**해 네모 배경용으로 재구성

## 신규 `빛·광택` 패턴
- `썬버스트 배경`
  - 중앙에서 햇살이 퍼지는 방사형 배경
  - 네모 캔버스 전체를 채움
- `소프트 썬버스트`
  - 더 부드럽고 파스텔한 방사형 햇살
- `글로시 선샤인`
  - 중앙 밝은 글로우 + 가장자리 광택 곡선 + 반짝이/도트 포인트
- `스파클 글로우`
  - 중앙 밝은 글로우 + 가벼운 반짝이 포인트

## 조절 가능한 값
- 색상 A / B: 햇살과 그라데이션 컬러
- 포인트: 반짝이 컬러
- 회전: 방사형 햇살 방향
- 디테일: 햇살 조각 수/강도
- 불투명도
- 오프셋

## 기존 기능
v1.4까지의 체크 강화, AI Pattern Designer, negative prompt, 컬러 추천, 다중 그라데이션, 원형 프사 미리보기 등의 기능을 그대로 유지해.
