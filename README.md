# Cute Pattern Studio v1.1

Cute Pattern Studio는 **귀여운 패턴 배경을 만들고 PNG로 저장하는 정적 웹앱**입니다.  
GitHub 업로드 후 Cloudflare Pages로 바로 배포할 수 있습니다.

## v1.1 핵심 업데이트

### 1) 선 색 자동 추천
현재 레이어 색상 조합을 기준으로 체크/플래드 계열에 잘 어울리는 **선 색**을 자동 추천합니다.
- 버튼: `선 색 자동 추천`
- 현재 레이어의 패턴 A / 패턴 B / 포인트 색을 참고해서 부드럽고 대비가 적절한 선 색을 자동 계산합니다.

### 2) 예쁜 컬러 조합 프리셋 추가
함께 쓰면 예쁜 컬러 조합을 바로 적용할 수 있는 추천 프리셋을 추가했습니다.
예시:
- 딸기 우유
- 버터 레몬
- 민트 소다
- 블루베리 요거트
- 피치 크림
- 세이지 체크

### 3) 기준 색상 자동 팔레트 추천
한 가지 **기준 색상**만 고르면 그 색에 어울리는 조합을 자동으로 추천합니다.
- 소프트 단색
- 비슷한 색 조합
- 포인트 대비
- 캔디 믹스

각 추천 팔레트는 아래 방식으로 바로 적용할 수 있습니다.
- `레이어 적용`
- `배경+레이어`

### 4) 기존 v1.0 기능 유지
- 체크 선 색상 수동 수정
- 선 두께 0~18px 조절
- 선 없는 체크(플랫 체크 / 플랫 3색 체크)
- 체크 전용 필터
- 3색 체크 / 다이아 체크 / 색연필 체크
- diagonal repeat / 원형 프사 미리보기
