# Cute Pattern Studio v0.9

Cute Pattern Studio는 **2000×2000 PNG 패턴 배경 생성용 정적 웹앱**입니다.  
GitHub에 업로드하고 Cloudflare Pages로 바로 배포할 수 있습니다.

## 이번 v0.9에서 반영한 핵심

### 1) 체크 패턴 추가 확장
첨부 참고처럼 활용도가 높은 체크 계열을 더 보강했습니다.

신규 체크 예시:
- 3색 체크
- 다이아 체크
- 다이아 깅엄
- 색연필 체크
- 파스텔 크레용 체크

모든 패턴은 기존처럼 **색상 수정 가능**합니다.

### 2) 오프셋 미세 증감 버튼 추가
`위치 X / 위치 Y` 항목에 다음 미세 조절 버튼을 추가했습니다.
- `-5`
- `-1`
- `+1`
- `+5`

숫자 직접 입력칸과 함께 더 정밀하게 반복 시작 위치를 맞출 수 있습니다.

### 3) 업로드 에셋 `diagonal repeat` 추가
업로드한 PNG / SVG 패턴에 다음 반복 방식이 지원됩니다.
- 모티프 반복
- 반복 타일
- 브릭 반복
- 하프드롭 반복
- **대각 반복(diagonal repeat)**

### 4) 원형 프사 미리보기 추가
메인 미리보기 아래에 **원형 프사 미리보기**를 추가했습니다.
프로필 사진처럼 원형 크롭했을 때 패턴이 어떻게 보이는지 바로 확인할 수 있습니다.
