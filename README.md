## v2.0.7
- 하트·도트·별·리본·꽃·구름·물방울 등 단순 모양 패턴을 **2줄 1세트(A/B)** 방식으로 반복
- B줄은 기본적으로 A줄 요소 사이의 중간 지점에서 시작하도록 자동 반 칸 이동
- A줄: X 위치 / Y 위치 / 각도 개별 조절
- B줄: X 추가 이동 / Y 위치 / 각도 개별 조절
- 3번째 줄부터 A/B 설정을 그대로 반복
- 요소 색상과 크기는 기존처럼 완전히 동일하게 유지
- 요소 단위 랜덤 위치·크기·각도 대신 줄 단위 배치 설정 사용
- 전체 패턴 회전 및 전체 X/Y 이동은 기존 공통 컨트롤 유지

- 개별 색상 지정 모드에서는 배경 / 패턴 A / 패턴 B / 패턴 C / 외곽선 색을 각각 직접 수정 가능


## v2.5.1
- 체크/플래드 패턴의 **Anchor Color 시각 일치도** 개선
- 스포이드나 HEX로 지정한 대표색을 단순 팔레트 기준색으로만 쓰지 않고, 미리보기에서 실제로 보이는 **가장 진한 체크/교차 영역의 색**으로 그대로 사용
- 자동 색상 모드에서 가장 진한 영역은 선택한 HEX를 1:1로 유지
- 중간톤 / 연한톤 / 거의 흰색 영역만 Anchor Color를 기준으로 자동 밝기 변환
- 적용 범위
  - 기본 체크 / 노갭 체크 / 깅엄 계열
  - 텍스처 체크
  - 겹침 체크 / 노갭 3톤 체크
  - 일반 플래드
  - 레이어드 패브릭 플래드
  - v2.5.0 레퍼런스 플래드 7종
- 특히 플래드 계열은 밴드 전체를 지나치게 진하게 만드는 대신, **가장 진한 교차 체크 영역만 Anchor Color와 정확히 일치**하도록 처리


## v2.5.2
- 체크/플래드 자동 색상 모드에서 **가장 진한 색만 따로 튀는 문제**를 개선
- `진한 기준색 연동` 모드에서는 스포이드/HEX로 찍은 색을 가장 진한 부분에 정확히 사용하고, 중간톤·연한톤도 같은 색상 계열로 함께 더 진하게 조정
- 기존의 투명도/겹침 때문에 실제 화면에서 더 연하게 보이던 렌더링도 삭제하지 않고 별도 프리셋으로 유지
  - 노갭 체크 · 소프트 투명
  - 노갭 3톤 체크 · 소프트 투명
  - 레이어드 패브릭 플래드 · 소프트 투명
  - 스티치 레이어 플래드 · 소프트 투명
- 기존 이름의 체크/플래드 프리셋은 `진한 기준색 연동` 방식으로 동작
- 새 소프트 프리셋은 대표색 팔레트는 유지하지만 기존처럼 투명도와 겹침을 적용해 실제 화면에서는 더 부드럽고 연하게 보임
- 편집 패널에 현재 프리셋의 `색상 렌더링 방식` 설명 추가
