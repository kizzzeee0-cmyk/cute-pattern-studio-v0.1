# Cute Pattern Studio v1.0

Cute Pattern Studio는 **2000×2000 PNG 패턴 배경 생성용 정적 웹앱**입니다.  
GitHub에 업로드하고 Cloudflare Pages로 바로 배포할 수 있습니다.

## 이번 v1.0 핵심 업데이트

### 1) 체크 선 색상 수정 가능
체크 패턴에서 색상 블록 사이를 가르는 선/외곽선용 색상을 별도로 조절할 수 있도록 개선했습니다.
- 새 색상 슬롯: **선 색**
- 기존 색상 수정 흐름 그대로 사용 가능

### 2) 체크 선 두께 조절 가능
레이어 편집에서 `선 두께`를 **0~18px** 범위로 조절할 수 있습니다.
- `0px` = 선 없이 색상만 보이는 체크
- `1px 이상` = 외곽선/격자선이 보이는 체크

### 3) 선 없는 체크 패턴 대응
체크 중간선을 완전히 없애고 색면만 남기는 형태도 쉽게 만들 수 있도록 개선했습니다.
- 선 두께를 0으로 조절 가능
- 신규 프리셋 추가:
  - `플랫 체크`
  - `플랫 3색 체크`

### 4) 체크 전용 필터 추가
패턴 라이브러리에서 체크 계열만 빠르게 모아볼 수 있도록 **체크 전용** 필터를 추가했습니다.
- 체크
- 깅엄
- 플래드
- 다이아 체크 등

### 5) 기존 v0.9 기능 유지
다음 기능도 그대로 포함되어 있습니다.
- 3색 체크 / 다이아 체크 / 다이아 깅엄
- 색연필 체크 / 파스텔 크레용 체크
- 오프셋 미세 증감 버튼
- diagonal repeat
- 원형 프사 미리보기
