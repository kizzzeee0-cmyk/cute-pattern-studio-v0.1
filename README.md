# Cute Pattern Studio v0.8

Cute Pattern Studio는 **2000×2000 PNG 패턴 배경 생성용 정적 웹앱**입니다.  
GitHub에 업로드하고 Cloudflare Pages로 바로 배포할 수 있습니다.

## 이번 v0.8에서 반영한 핵심

### 1) 몽글·추상 패턴 정리
- 사용성이 낮은 **몽글·추상 계열 패턴**을 라이브러리에서 정리했습니다.
- 대신 실제 활용도가 높은 패턴 위주로 더 깔끔하게 구성했습니다.

### 2) 체크 무늬 패턴 추가
신규 체크 계열 예시:
- 마시멜로 체크
- 피크닉 체크
- 윈도우페인 체크
- 레이어드 체크
- 마이크로 깅엄

### 3) 오프셋 초기화 + 숫자 직접 입력칸 추가
- `위치 X`, `위치 Y` 슬라이더에 **숫자 직접 입력칸**을 추가했습니다.
- `오프셋 초기화` 버튼으로 위치를 바로 0,0으로 되돌릴 수 있습니다.

### 4) 업로드 에셋 반복 방식 추가
업로드한 PNG / SVG 패턴에 다음 반복 방식을 추가했습니다.
- `브릭 반복`
- `하프드롭 반복`

### 5) 유지되는 주요 기능
- 요소 크기 / 각도 / 위치 랜덤 토글
- `깔끔 정렬 적용` 버튼
- 기본 레이어 1개로 시작, 필요 시 추가 레이어 생성
- 레이어 순서 이동 / 삭제
- 배경색 포함 PNG 저장
- 투명 배경 저장 지원
- 업로드 SVG/PNG/JPG 반복 패턴화
- SVG 단색 변환
- 즐겨찾기 / 내 프리셋 저장
- 참고 이미지 팔레트 자동 추출
- 심리스 타일 PNG 저장
