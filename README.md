# Cute Pattern Studio v2.3.0

패턴 편집 중심으로 복원한 안정화 업데이트입니다.

## v2.0.5
- 완성형 디자인 배경 영역 제거
- **점선 체크 / Dashed Grid** 패턴 추가
  - 선 색상 / 투명도 / 두께
  - 점선 길이 / 점선 간격
  - 격자 가로 / 세로 간격
  - 전체 회전
  - X / Y 오프셋
  - round line cap
- 대표색을 **Anchor Color(가장 진한 기준색)** 로 사용하는 자동 톤 변환
- 기존 7색 빠른 선택 유지
- 자유 컬러 피커 / HEX / 스포이드 지원
- 거의 흰색이던 영역은 선택색의 아주 옅은 틴트만 적용
- 좌측 패턴 라이브러리 휠 스크롤 안정화
- 기존 레이어, 배경, 수채화, 비네트, 업로드 에셋, 프리셋 저장, PNG/심리스 저장 기능 유지

기본 작업 크기: 2000 × 2000px

## v2.0.5 추가 수정
- 상단 패턴 카테고리 탭이 항상 보이도록 레이아웃 복구
- 점선 체크의 `패턴 크기`를 전체 격자 스케일로 연결
- 가로/세로 격자 간격은 기존대로 개별 조정 가능


## v2.0.5 추가 수정
- 패턴 카테고리 탭을 라이브러리 상단으로 이동하고 항상 표시되도록 복구
- 점선 체크의 전체 크기가 격자 간격뿐 아니라 점선 길이/간격/두께에도 함께 적용
- 점선 체크는 Anchor Color 자동 변경 시 캔버스 배경색을 강제로 바꾸지 않음
- 흰색 점선 기본 투명도를 38%로 조정해 파스텔 배경에서 더 안정적으로 보이도록 수정


## v2.0.5
- 레이어드 패브릭 플래드의 45° 해칭 범위를 확대
- 중간 진함 이상 밴드/체크 영역에 빠짐없이 해칭 적용
- 해칭 사용 ON/OFF 토글
- 해칭 불투명도 0~100% 조절
- 기본 해칭 불투명도 40%


## v2.0.5
- 땡땡이/도트 계열은 모든 반복 도형을 한 가지 색상으로 통일
- 도트, 하트, 별, 반짝이, 리본, 꽃, 구름, 물방울 등 단순 반복 모양의 크기를 완전히 동일하게 고정
- 불규칙 도트도 위치만 흔들릴 수 있고 도트 자체 크기는 동일
- 단순 모양 패턴의 개별 색상 모드에는 '모양 색상' 1개만 표시
- 단순 모양 패턴에서는 '요소 크기 랜덤'을 비활성화해 실제 렌더 결과와 UI를 일치


## v2.0.6
- 도트·하트·별·리본·꽃·구름·물방울 등 단순 반복 모양의 개별 방향을 완전히 동일하게 고정
- 단순 모양은 색상 1색 · 크기 동일 · 방향 동일 규칙으로 렌더링
- 기존 저장값에 각도 랜덤이 켜져 있어도 자동으로 고정 방향으로 복구
- 단순 모양 패턴에서는 '요소 각도 랜덤' 옵션을 비활성화
- 전체 방향은 기존 '회전' 슬라이더로 모든 반복 요소를 함께 회전


## v2.0.7
- 하트·도트·별·리본·꽃·구름·물방울 등 단순 모양 패턴을 **2줄 1세트(A/B)** 방식으로 반복
- B줄은 기본적으로 A줄 요소 사이의 중간 지점에서 시작하도록 자동 반 칸 이동
- A줄: X 위치 / Y 위치 / 각도 개별 조절
- B줄: X 추가 이동 / Y 위치 / 각도 개별 조절
- 3번째 줄부터 A/B 설정을 그대로 반복
- 요소 색상과 크기는 기존처럼 완전히 동일하게 유지
- 요소 단위 랜덤 위치·크기·각도 대신 줄 단위 배치 설정 사용
- 전체 패턴 회전 및 전체 X/Y 이동은 기존 공통 컨트롤 유지


## v2.0.8
- 패턴 위에 적용되는 **양방향 세로 그라데이션 오버레이** 기능 추가
- 그라데이션 1 / 그라데이션 2 각각 독립 ON/OFF
- 방향: 위 → 아래 / 아래 → 위
- 각 오버레이별 색상, 불투명도, 시작 위치, 끝 위치, 퍼지는 정도 독립 조절
- 최대 2개 오버레이 동시 적용
- 기존 패턴 색상과 구조는 바꾸지 않고 별도 overlay layer로 합성
- 미리보기와 PNG 저장 결과에 동일하게 적용
- 기본값: 상단 하늘색 0~35%, 하단 파란색 70~100%


## v2.1.0
- 신규 **그래픽 배경** 카테고리 추가
- 같은 감성을 유지하면서 구도가 다른 5종 스타일 제공
  - 그래픽 코너 집중형
  - 그래픽 사선 흐름형
  - 그래픽 프레임형
  - 그래픽 중앙 여백형
  - 그래픽 전체 분산형
- 완성 이미지를 등록한 것이 아니라 Canvas 벡터 도형으로 실시간 생성
- 원 / 링 / 점 / 점선 / 둥근 막대 / 선 / 스파클 / 다이아 / 스트라이프 원 / 체크 조각 등을 조합
- seed 기반으로 같은 스타일 안에서도 위치와 조합이 달라짐
- 그래픽 스타일 전용 설정
  - 구도 새로 섞기
  - 요소 세트: 자동 / 기하학 / 귀여운 포인트 / 스파클 / 미니멀
  - 중앙 여백 40~80%
  - 둥근 막대 크기
  - 원·링 크기
  - 도형 전체 크기
  - 장식 밀도
- 중앙 여백을 확보해 캐릭터·타이포 배치에 방해되지 않도록 설계
- 기존 Anchor Color, 그라데이션 오버레이, PNG 저장과 함께 사용 가능
- 흐릿한 AI식 장식 없이 또렷한 2D 벡터형 도형만 사용


## v2.2.0
- 기존 그래픽 배경의 요소가 한곳에 뭉치는 문제를 개선
- 가장자리 슬롯 기반 배치로 상/하/좌/우에 요소가 더 고르게 분산
- 분산 균형 슬라이더 추가: 높을수록 정돈되고 고르게, 낮을수록 자연스러운 랜덤성 증가
- 신규 그래픽 프레임 5종 추가
  - 그래픽 원·링 프레임
  - 그래픽 롱 캡슐 프레임
  - 그래픽 점선 프레임
  - 그래픽 스트라이프 프레임
  - 그래픽 밸런스 믹스
- 그래픽 요소 확장: 긴 캡슐 / 외곽선 캡슐 / 스트라이프 캡슐 / 평행 막대 / 점선 직선 / 점선 링 / 원 / 링 / 버블 / 도트 그리드 / 스트라이프 원 / 체크 조각 / 스파클 / 다이아
- 그래픽 배경 전용 크기 조절 확장: 작은 장식 / 큰 프레임 요소 / 긴 막대·캡슐 / 원·링 / 도형 전체 크기
- 요소 세트 확장: 전체 혼합 / 원·링 중심 / 긴 막대·캡슐 중심 / 점선·도트 중심 / 기하학 / 귀여운 포인트 / 스파클 / 미니멀
- 그래픽 배경에서 크기와 밀도를 조절해도 seed가 자동 변경되지 않아 구도를 유지한 채 세밀하게 조절 가능
- Anchor Color 개선: 사용자가 고른 색이 가장 진한 기준색으로 유지되고, 중간톤/연한톤/화이트가 자동으로 조합됨


## v2.3.0
- 신규 **하트·버블 그래픽** 카테고리 추가
- 6개 생성형 스타일 추가
  - 하트·버블 프레임
  - 하트 코너 집중형
  - 하트·버블 상하 흐름형
  - 하트·버블 좌우 흐름형
  - 하트·버블 전체 분산형
  - 에어리 하트 버블
- 완성 이미지를 등록한 방식이 아니라 Canvas 벡터 도형으로 실시간 생성
- 중앙을 가르는 큰 선/막대 없이 캐릭터와 타이포를 올릴 공간을 유지
- 하트 제어: 개수 / 최소·최대 크기 / 불투명도 / 채움·아웃라인 비율
- 버블 제어: 개수 / 최소·최대 크기 / 불투명도 / 테두리 두께 / 하이라이트 강도
- 반짝이 개수 / 가장자리 집중도 / 분산 균형 조절
- 배치 다시 섞기로 현재 스타일을 유지한 채 위치 조합만 새로 생성
- **배경색 자동 조화** 기본 ON
  - 배경색을 기준으로 진한 포인트색 / 중간톤 / 연한톤 / 화이트를 자동 생성
  - 배경색 피커 / HEX / 스포이드 변경 시 하트·버블 색도 즉시 조화
  - Anchor Color를 직접 바꾸거나 개별 색상 모드로 전환하면 자동 조화를 해제하고 수동 색상 유지
