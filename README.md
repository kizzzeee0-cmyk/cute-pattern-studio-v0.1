# Cute Pattern Studio v1.3.1

Cute Pattern Studio는 귀여운 패턴 배경을 만들고 PNG / 심리스 타일 PNG로 저장하는 정적 웹앱이야.
Cloudflare Pages + Functions 구조를 사용하고, v1.3.1에서는 **패턴 라이브러리 UI 폭 조정 + 겹침형 3톤 체크 패턴 강화**가 추가되었어.

## v1.3.1 핵심 변경점
- **패턴 라이브러리 UI 조정**
  - 왼쪽 패널 폭 확장
  - 패턴 카드/텍스트 크기 소폭 조정
  - 잘려 보이던 카드 가독성 개선
- **겹침형 3톤 체크 렌더링 추가**
  - 한 색의 밴드가 가로/세로로 겹쳐서
    - 0겹 = 배경색
    - 1겹 = 연한 톤
    - 2겹 = 더 진한 톤
  - 첨부 예시처럼 자연스럽게 3톤이 보이는 체크 구현
- **관련 체크 프리셋 보강**
  - `3톤 겹침 체크`
  - `플랫 3톤 체크`
  - `노갭 3톤 체크`
  - `소프트 겹침 체크`
  - `에어리 겹침 체크`
- **대표색 1개 → 3톤 자동 배색 기능 유지**
  - 체크 전용 색상 생성 UI 그대로 사용 가능

## 추천 사용법
### 1) 첨부 예시 같은 블루 체크
- 패턴: `노갭 3톤 체크` 또는 `에어리 겹침 체크`
- 대표색: 하늘색/민트/옐로우 등 1개 선택
- `3톤 생성 적용` 클릭

### 2) 여백 없는 깔끔 체크
- 패턴: `노갭 체크`
- 간격: 0
- 선 두께: 0

### 3) 종이 찢김 연출 체크
- 패턴: `찢어진 체크`

## 주요 파일
- `styles.css` — 패턴 라이브러리 폭/카드 UI 조정
- `patterns.js` — 겹침형 체크 렌더러 및 새 프리셋 추가
- `app.js` — 저장 버전 키 갱신
- `V1_3_1_DEV_SPEC.md` — 이번 버전 개발 명세서
